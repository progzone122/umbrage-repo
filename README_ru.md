# Umbrage Repository
[English](./README.md) | [Русский](./Readme_ru.md)

Репозиторий с пользовательскими шаблонами MediaTek-устройств для проекта Umbrage.

## Что такое шаблон?
Шаблон в контексте Umbrage - это набор `DA`/`Auth`/`Preloader` файлов и метафайла в формате `.yml`, который позволяет инструментам, совместимые с проектом Umbrage, определить, какие файлы подходят конкретному устройству.

Один шаблон может содержать несколько версий.

## Что такое версия?
Версия шаблона - это отдельный набор DA/Auth/Preloader-файлов для одного устройства. 

Разные версии могут отличаться из-за ревизии устройства, версии прошивки, используемого эксплоита или просто потому, что конкретный набор файлов оказался совместимым с определённым устройством.

## Правила оформления шаблонов
- **1 устройство == 1 шаблон.** Исключение - случаи, когда устройство представляет собой буквально одну и ту же плату с одной и той же прошивкой, но с разными распаянными на ней компонентами.
- Значения в полях `vendor` и `model` должны начинаться с заглавной буквы.
- Значение в поле `codename` должно быть написано в нижнем регистре.
- Постарайтесь кратко описать в полях `name` и `description`, какой функционал предоставляют эти файлы или какие нюансы следует учитывать. Для примеров оформления можно посмотреть другие шаблоны.
- Используйте `default: true` только для тех версий шаблона, которые были протестированы с Umbrage и работают на 100%. Эта строка означает, что вы рекомендуете другим использовать данную версию и лично протестировали её работоспособность.

## Добавление или редактирование шаблона в репозитории
В Umbrage Beta 0.1.1 появился удобный генератор шаблонов - именно через него рекомендуется вносить изменения в шаблоны.

1. Запустите Umbrage, выберите шаблон для редактирования или вручную выберите файлы для нового шаблона.
2. Подключите устройство, чтобы проверить работоспособность выбранных файлов.
   > Если у вас по какой-то причине прямо сейчас нет возможности проверить файлы на работоспособность, вы можете использовать аргумент `--skip-conn` при запуске Umbrage, чтобы пропустить этап подключения устройства.
   >
   > **ПОМНИТЕ!** Если вы не проверяли работоспособность устройства с указанными файлами в Umbrage, мы **НАСТОЯТЕЛЬНО ПРОСИМ ВАС** не отмечать эту версию шаблона как `Recommend this is a default version` или `default: true`.

3. Откройте `Other` → `Template generator` и экспортируйте метафайл для шаблона.

4. Создайте форк этого репозитория и переместите **ВСЕ используемые файлы** в директорию `files` **БЕЗ ИЗМЕНЕНИЯ ИХ НАЗВАНИЙ**.

   Если обнаружится конфликт файлов, сравните их контрольные суммы с помощью `sha256sum`. Если контрольные суммы совпадают, пропустите замену - этот файл уже есть в репозитории.

   В противном случае добавьте цифру `2`, `3`, `4` и т. д. в конец названия файла, чтобы решить конфликт, а затем отредактируйте метафайл, указав новые названия файлов.

5. Переместите созданный метафайл в `meta/<vendor>/<codename>.meta.yml`. *Если директории с названием вашего вендора ещё не существует, создайте её.*

6. Откройте Pull Request и внесите необходимые правки по замечаниям.
